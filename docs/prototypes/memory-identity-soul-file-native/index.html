Nion

你的长期档案与助手默契

设计意图

这版原型走的是“个人档案中心 + 文档资产”的混合模型。普通用户先看懂，再逐步感知 `MEMORY.md`、`IDENTITY.md`、`SOUL.md`。

Personal Context Center

让助手记住该记住的，而不是把你推进后台配置台

这不是给开发者用的控制面板。它更像一个清晰、安静、可回看的个人档案中心：你可以看到当前活跃记忆、长期档案、身份主档，以及这个助手的长期灵魂文件。

当前设计锚点

  • 外层像档案中心
  • 内层保留文件原生资产感
  • 编辑是局部的，不是整页表单墙

为什么这样设计

  • 普通用户先看到“这是我的身份主档”
  • 系统仍然可以把这份文件解析成结构化 profile
  • 不需要把全部信息做成一面大表单
日常体验

新对话里，助手会默认带着这些信息，不需要每次重新解释。

Section Editing

局部编辑，而不是整页填表

编辑是针对某一段进行的。这样普通用户不会被十几个输入框同时轰炸，也更接近真实文档的修改体验。

这是高保真原型里最重要的一刀：页面主体是文档，编辑入口是局部的。这样才像产品，不像后台。
